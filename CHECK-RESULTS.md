## Обновление

Постоянная ссылка уже работает. Проверки запускаются по расписанию каждые шесть часов с возможной задержкой GitHub. **Автоматическая запись M3U пока выключена:** workflow имеет `contents: read`. Результат каждого запуска сохраняется в архив `sv-iptv-check-results` на 7 дней. Слово `published` внутри этого архива обозначает создание локальной сборки в запуске; оно само по себе не означает обновления постоянной ссылки.

История в репозитории соответствует вечернему архиву: оба запуска начинали с исходной истории, поэтому утреннее наблюдение в вечернюю историю автоматически не добавлялось. После включения записи последующие проверки смогут последовательно накапливать историю и обновлять M3U. Для этого требуется разрешение `contents: write`.
